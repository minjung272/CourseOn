# Course On 수동 브라우저 QA

## 실행 전 준비

1. `npm install`
2. 로컬은 `npm run dev`, 배포는 Netlify 주소로 실행
3. Chrome 일반 창과 모바일 화면(390px)에서 각각 확인
4. 결과를 `통과 / 실패 / 확인 불가`로 기록

## 완료 기준

- 핵심 흐름 `HOME, COURSE, REC, MAP, BOARD, CHAT`에 실패 항목이 없어야 한다.
- `COURSE-08`, `ROUTE-01`은 현재 추가 개선 후보이므로 실패 시 별도 이슈로 등록한다.
- 오류가 발생하면 주소, 입력값, 콘솔 오류, 화면 캡처를 함께 기록한다.
