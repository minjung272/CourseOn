# CourseOn 수동 브라우저 QA

## 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`에 접속하고 아래 순서대로 확인한다.

## 1. 공통 화면과 라우터

- [ ] Header 메뉴로 홈·여행코스·맞춤추천·지도·게시판·챗봇에 이동한다.
- [ ] 각 주소에서 새로고침해도 같은 화면이 유지된다.
- [ ] 모바일 너비에서 메뉴를 열고 닫을 수 있다.
- [ ] 존재하지 않는 `/qa-not-found`에서 404 안내가 보인다. 현재 엄격 QA 실패 항목이다.

## 2. 여행코스

- [ ] `/courses`에서 카드가 로딩되고 이미지·제목·태그가 보인다.
- [ ] 제목 일부를 검색하면 해당 카드만 남는다.
- [ ] 존재하지 않는 검색어를 입력하면 빈 결과 안내가 보인다.
- [ ] 태그 필터를 선택하고 초기화할 수 있다.
- [ ] 정렬 값을 바꾸면 카드 순서가 변한다. 현재 동작하지 않을 가능성이 있다.
- [ ] 카드의 상세보기를 누르면 `/courses/:id`로 이동한다.
- [ ] 이미지가 없는 코스에서 기본 이미지가 표시된다.
- [ ] `/courses/not-found`에서 코스 없음 안내가 보인다.
- [ ] 상세 화면의 지도 보기와 추천받기 버튼이 선택 코스를 다음 화면에 전달한다.

## 3. 맞춤 추천

- [ ] `/recommend`에서 동행·관심사·지역·스타일·교통을 각각 바꾼다.
- [ ] 선택한 다섯 조건이 결과 화면에 모두 표시된다.
- [ ] 조건 조합을 바꾸면 추천 TOP 3의 코스 또는 순서가 달라진다. 현재 엄격 QA 실패 항목이다.
- [ ] 결과 카드의 상세보기가 실제 코스 상세 화면으로 연결된다.
- [ ] 결과 화면 새로고침 후에도 쿼리 조건이 유지된다.

## 4. 지도

- [ ] `/map`에서 검색어와 구 필터를 바꾸면 목록과 마커가 함께 바뀐다.
- [ ] 테마·코스 유형·소요 시간 필터가 각각 동작한다. 현재 3개가 상태에 연결되지 않았다.
- [ ] 필터 결과가 0건이면 이전 코스 팝업이 남지 않는다.
- [ ] 새로고침 버튼이 목록을 초기 상태로 되돌린다.
- [ ] 모든 지도 카드의 상세보기가 `/courses/:id`로 이동한다. 일부 `detailId`가 누락됐다.
- [ ] 상세 화면에서 지도 보기로 이동하면 해당 코스가 선택된다.

## 5. 게시판

- [ ] `/boards/write`에서 게시글을 작성한다.
- [ ] 작성한 글을 조회하고 조회수가 증가하는지 확인한다.
- [ ] 틀린 비밀번호로 수정·삭제하면 거부된다.
- [ ] 올바른 비밀번호로 수정한 뒤 삭제한다.
- [ ] 빈 제목·작성자·내용·비밀번호를 제출하면 입력 안내가 보인다.
- [ ] 5MB에 가까운 이미지를 첨부했을 때 오류 문구가 명확하게 보인다.
- [ ] API 서버를 끈 상태에서 목록을 열면 사용자용 오류 안내가 보인다.

## 6. 챗봇

- [ ] `강서구 산책 코스 추천해줘`에 강서구 카드가 최대 3개 표시된다.
- [ ] 이어서 `그중 야경은?`을 질문하면 앞의 지역 조건을 유지한다.
- [ ] `1+1은?`에는 코스 카드가 표시되지 않는다.
- [ ] 빈 질문과 500자 초과 질문이 거부된다.
- [ ] 추천 카드의 상세 링크가 실제 코스를 연다.
- [ ] OpenAI 키 누락·사용량 초과·서버 오류가 서로 다른 안내로 표시된다.

## 완료 기준

- 일반 회귀 테스트 `npm test` 통과
- 빌드 `npm run build` 통과
- 실행 중 경로 점검 `npm run test:smoke` 통과
- 엄격 QA `npm run test:qa`의 실패 항목을 0개로 만든다.
